# Taverna do Rogerio
O Restaurante Taverna do Rogério, em Carcavelos, oferece uma experiência gastronómica mediterrânica, europeia e portuguesa num ambiente acolhedor e moderno. Ideal para almoços e jantares, dispõe de opções sem glúten, música ao vivo, Wi-Fi gratuito, serviço de mesa, takeaway e reservas, garantindo conforto e qualidade a todos os clientes.
